# PRODUCT.md

## Project

AI-Powered Development Control & Regulation (DCR) Assistant for Mumbai Projects ("AI-DCR")

## Purpose

Significantly reduce the time architects and planners spend searching through Mumbai Development Control & Promotion Regulations (DCPR), National Building Code (NBC), and other applicable regulations during the conceptual and planning stages of a project.

Instead of manually reading hundreds of pages and repeatedly searching for the same clauses, the application provides:
- Intelligent rule extraction
- Instant regulation lookup
- Automated planning calculations
- Project-specific compliance summaries
- AI-powered guidance during design
- FAQs based on inputs from other projects

The application is intended to become the first point of reference before starting any architectural design.

## Problem Statement

Current workflow is inefficient because every new project requires:
- Reading 500–600 pages of regulations
- Searching for the same clauses repeatedly
- Interpreting legal language
- Performing manual calculations
- Cross-checking multiple regulations
- Preparing planning notes from scratch

Knowledge from previous projects is limited to the person who worked on it and is lost when they leave the firm. This consumes several hours before actual design work begins, and increases dependency on specialized liaisoning consultants.

## Objectives

1. Digitize all applicable rule books
2. Make every regulation searchable
3. Automatically identify rules applicable to a project
4. Perform planning calculations
5. Explain regulations in simple language
6. Generate project-specific planning notes
7. Reduce human error
8. Reduce project initiation time by more than 70%
9. Analyze which regulation is more profitable/advantageous for a given design
10. **BHAG:** Calculate premiums
11. **BHAG:** Prepare project feasibility reports

## Primary Users

| User | Needs |
|---|---|
| Architects | Concept planning, feasibility studies, design development |
| Junior Architects | Rule verification, learning regulations, compliance checking, calculating |
| Senior Architects | Planning review, decision making |
| Town Planners | Regulation interpretation |

## Core Modules

| # | Module | Purpose |
|---|---|---|
| 1 | Regulation Library | Store every regulation (Mumbai DCPR, NBC, Fire regs, Environmental regs, future rule books) in a structured, searchable database |
| 2 | AI Rule Search | Instant natural-language lookup across the regulation library |
| 3 | Project Creation | Capture project details (plot, occupancy, road width, zoning) incrementally |
| 4 | Rule Recommendation Engine | Automatically surface applicable rules based on project type |
| 5 | Planning Extract Generator | Produce a project-specific planning extract document from structured data + retrieved clauses |
| 6 | Planning Calculators | FSI, Parking, Open Space, Staircase, Toilet, Fire, Refuge Area, and more |
| 7 | AI Explanation Engine | Explain regulatory language in plain terms |
| 8 | Compliance Checker | Convert rules into structured pass/fail checks with risk levels |
| 9 | AI Chat Assistant | Conversational interface over the regulation + project knowledge base |
| 10 | Drawing Assistant *(Future)* | CAD/PDF drawing analysis against regulations |

## Success Metrics

- Project initiation time reduced by 70%+
- Search results always grounded in retrieved clauses, not general AI knowledge
- Adoption across Architects, Junior Architects, Senior Architects, and Town Planners as the first reference point before design work begins
