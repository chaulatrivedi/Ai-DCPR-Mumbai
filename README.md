# AI-DCR — Mumbai DCPR Assistant

AI-powered assistant that helps architects and planners search, understand, and apply Mumbai Development Control & Promotion Regulations (DCPR), NBC, and related regulations during project planning.

See `docs/PRODUCT.md` for the full product spec, `docs/ARCHITECTURE.md` for the technical architecture, `docs/DECISIONS.md` for the reasoning behind key choices, and `docs/TASKS.md` for the milestone/task tracker.

## Status

Early setup (Milestone 0). Not yet functional.
